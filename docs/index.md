# FCS Web

O `fcs-web` é o frontend da Conexão Solidária. Ele oferece os fluxos públicos,
de Doador e de GestorONG e consome as APIs da plataforma.

## Operação

- Catálogo: [componente FCS Web](https://github.com/group10-tc-01/fcs-web/blob/main/catalog-info.yaml)
- Pipeline: [GitHub Actions](https://github.com/group10-tc-01/fcs-web/actions)
- Deploy: namespace `fcs-web` no K3s
- Observabilidade: serviço `fcs-web` no Datadog

As instruções de desenvolvimento local permanecem no [README](../README.md).
